# CLAUDE.md

Українськомовний туторіал по FMC (збірка кубика Рубіка на кількість ходів).
React + Vite, без бекенду — увесь контент статичний.

## Структура

- `src/content/*.js` — **весь текст гайду** (параграфи, ресурси, таблиці) як
  прості дані, окремо від компонентів. Це джерело правди — коли треба
  виправити чи додати текст, редагуй тут, а не в JSX.
  - `navigation.js` — єдине джерело структури сайту: список сторінок і їхніх
    розділів (`id` + `label`). Sidebar, мобільне меню й scrollspy читають
    саме звідси. Кожен `id` тут має відповідати `id` секції в контент-файлі
    цієї сторінки (`blockbuilding.js`, `domino.js`, `bonus.js`) або секції на
    `HomePage`.
  - `iceberg.js` — дані для інтерактивної "карти техніки" на головній.
  - `communities.js` — посилання на спільноти (Telegram/Discord/FB) і список
    контестів.
- `src/components/ui/` — дрібні переюзабельні компоненти рендеру контенту:
  `Prose` — диспетчер типів блоків (`p`, `list`, `note`, `quote`, `steps`,
  `cycleTable`, `commutatorTable`, `glossary`, `schedule`, `image`,
  `guideLink`). Щоб додати новий тип блоку — додай `case` у `Prose.jsx` і
  маленький компонент поруч.
- `src/components/layout/` — каркас сторінки: `AppShell` (grid + мобільна
  шухляда меню), `Sidebar`, `Topbar`, `Footer`.
- `src/pages/` — по одній сторінці на розділ (`HomePage`, `BlockbuildingPage`,
  `DominoPage`, `BonusPage`); кожна просто мапить масив секцій з відповідного
  content-файлу через `<Section>`.
- `src/utils/inlineMarkup.jsx` — міні-парсер `**bold**`, `` `code` ``,
  `[текст](url)` для рядків контенту (внутрішні посилання `/...` йдуть через
  `react-router` Link).
- `src/hooks/` — `useScrollToHash` (скрол до якоря при зміні маршруту),
  `useActiveSection` (scrollspy для підсвітки активного розділу в сайдбарі).

## Стиль

Дизайн-токени (кольори, шрифти, радіуси) — в `src/index.css` на `:root`.
Кожен компонент має свій CSS Module. Тема — темна, космічна (акценти
`--accent`/`--accent-2`, шрифти Space Grotesk / Inter / Space Mono).

## Джерело контенту

Оригінальний гайд (докладніше, з локальними докс-гайдами по DR/HTR) лежить у
Google Docs — власник надсилав `.docx`/`.md` версію під час першої побудови
сайту. Якщо контент треба звірити чи розширити — питай користувача за
посиланням, у репозиторії оригінал не зберігається.
